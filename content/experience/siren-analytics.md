## The problem

SiViZ gives government, NGO and finance clients real-time insights from their
data. Clients wanted to automate recurring work, like "a weekly digest of my
performance metrics", without building the workflow themselves.

## What I built

- Backend logic in Python on the OpenAI API that generates a workflow from a
  plain-text prompt, with access to the client's own data.
- A multi-turn clarification system: when a prompt is unclear, the AI asks
  follow-up questions before it builds anything.
- REST APIs in Java Spring Boot with API-key access to SiViZ tools, so clients
  can plug them into automation platforms like n8n.
- Text interfaces, smart agents and automation flows for email, reporting and
  task management.

## Results

The workflow generator saved clients up to **10 hours of manual work per week**.
